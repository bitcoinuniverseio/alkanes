# Security policy

## Reporting a vulnerability

**Do not open a public issue for a security problem.**

Report privately through GitHub security advisories:
<https://github.com/bitcoinuniverseio/alkanes/security/advisories/new>

Include what you observed, how to reproduce it, and what you think the impact is. If a specific transaction,
script hex, or alkane id is involved, include it.

## What belongs where

| Kind of problem | Where to report |
|---|---|
| Wrong or misleading protocol documentation on this site, especially anything that could cause a user to build a payload that loses funds | This repository, privately |
| A flaw in this site itself, for example the protostone tool producing an incorrect script | This repository, privately |
| A flaw in the Alkanes protocol implementation or indexer | [bitcoinuniverseio/alkanes-rs](https://github.com/bitcoinuniverseio/alkanes-rs) |
| A flaw in a Bitcoin Universe product | That product's repository, privately |

Documentation errors are treated as security issues here when they could lead to asset loss. Alkanes payload
mistakes fail silently on chain, so a wrong example is not a cosmetic problem.

## Scope

In scope:

- Incorrect encoding or decoding rules stated anywhere on the site
- Incorrect worked examples, script hex, or test vectors
- Defects in `protostone.js` that produce a wrong or unsafe result
- Claims of product capability that are not actually supported

Out of scope:

- Vulnerabilities in GitHub Pages itself
- Missing security headers that GitHub Pages does not allow this repository to set
- Reports generated by automated scanners with no demonstrated impact

## Handling

Reports are acknowledged through the advisory thread. Documentation corrections that could affect funds are
published as soon as they are confirmed, and recorded in `changelog.html`.

## Safety notes for users

- Verify a payload before signing it. Decode the `OP_RETURN` script and confirm the protocol tag is `1`, the
  alkane id is the one you mean, the amount is in base units, and the output index is the recipient.
- This site never asks for a private key, a seed phrase, or a signature. Nothing you type into the protostone
  tool is stored or transmitted.
- An `OP_RETURN` that does not begin `6a 5d` is not an alkanes payload, whatever it claims to be.
